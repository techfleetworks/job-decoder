## Findings

None at high/med. Two low observations, both cleared, no waiver required:

- **@question:dependency @severity:low** — `PILL_BY_SET` (hat-set → user-facing pill wording)
  lives in the domain projection file. Consistent with the existing domain-owned display
  strings (interview text, outcome templates in `prep.ts`), and tested as part of the
  view-model contract. A long-term "pill copy could move to a presentation constant"
  preference, not a defect.
- **@question:boundary @severity:low** — the highlights shown-vs-"More from this Hat" split
  is in `PrepView`. Explicitly designated a presentation threshold by ADR-0045 §Consequences
  (the projection returns the full ordered, matched-marked list; the view picks the cutoff),
  so cleared.
